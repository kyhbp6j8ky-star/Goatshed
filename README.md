# Goatshed Foto-V2

Statische responsive Homepage mit HTML, CSS und Vanilla JavaScript.

## Starten

Öffne `index.html` direkt im Browser oder starte lokal:

```bash
python3 -m http.server 8000
```

Danach: `http://localhost:8000`

## Audio ergänzen

Lege die MP3-Dateien exakt mit diesen Namen in `assets/audio/`:

- `GOATSHED - Bubble of Dreams.mp3`
- `When god calls your name - GOATSHED - live.mp3`
- `18 Wheels - GOATSHED - live.mp3`
- `Shattered Dreams.mp3`

## Vor Veröffentlichung

1. `booking@goatshed.ch` durch die echte Kontaktadresse ersetzen.
2. Songtitel und MP3-Dateinamen prüfen.
3. Falls gewünscht, das PNG-Logo durch `goatshed.svg` ersetzen und die beiden Logo-Pfade in `index.html` anpassen.
4. Die Dateien in ein GitHub-Repository hochladen und GitHub Pages für den Branch `main` aktivieren.
